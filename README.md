# GPT-2 from Scratch

A learning project to build a GPT-2-style decoder-only Transformer in PyTorch from scratch.

## Current status

The repository currently contains reference material for the implementation. Model code, training scripts, and runnable examples have not been added yet.

## Reference

- [GPT-2 Transformer video transcript](GPT2-Transformer-Video-Transcript.md)
- [Building GPT-2 from scratch, explained line by line](https://www.youtube.com/watch?v=CfJ3Cxtlcps)

The transcript may contain transcription errors; verify code and formulas against the video when implementing the model.

## Planned scope

Token and positional embeddings, causal self-attention, Transformer blocks, next-token training, and autoregressive text generation.

Setup and usage instructions will be added as the code develops.
